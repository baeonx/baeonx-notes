## 1. 核心思想：树 = 一串比较，比较 = 一张表

一棵决策树的判定过程，本质是一串**阈值比较**：

```
[3, 0, 4, 1, 5, 2]
```

```
特征 x <= 阈值 t ？  是→走左；否→走右
```

如果把每个内部节点的比较看作"查表"，树的整个判定就是**按顺序查几个表**。Flowrest 的巧妙之处：

| 树的成分                       | 翻译成 P4 表               | 匹配类型                      |
| ------------------------------ | -------------------------- | ----------------------------- |
| 一个特征上的所有分裂点（阈值） | 特征表（`table_feature*`） | **range**（区间匹配）         |
| 一条"根到叶"的完整路径         | 码表（`code_table*`）      | **ternary**（带掩码精确匹配） |
| 多棵树的结论合并               | 投票表（`voting_table`）   | **exact**                     |

```
一条报文的特征值
      │
      ▼
 特征表（每特征一张）      输出：每个特征命中区间 → 一位位"0/1 码"
      │
      ▼
  码表（每棵树一张）      输出：整棵树的路径匹配 → 类别 + 置信度
      │
      ▼
   投票表（一张）         输出：三棵树多数表决 → 最终类别
```

> 一句话记忆：**特征表负责"算"，码表负责"走路径"，投票表负责"定结论"。**

## 2. 特征表：把特征值编码成位串

### 2.1 问题

每棵树在每个特征上有一组分裂阈值。同一特征在所有树上的阈值合起来，把取值范围切成若干**区间**。落在哪个区间，就决定了该特征在每个分裂节点上的"是/否"答案。

以 `feature0 = Packet Length Total` 为例，三棵树里该特征共有 N 个分裂节点，每个节点有一个阈值。这些阈值排序后把取值范围切成 N+1 个区间。

### 2.2 第一步：`get_splits` —— 收集所有分裂点

遍历每棵树、每个内部节点，抽出 `(树号, 节点ID, 左子, 右子, 阈值, 特征名)`：

```python
def get_splits(forest, feature_names):
    data = []
    for t in range(len(forest.estimators_)):
        clf = forest[t]
        n_nodes = clf.tree_.node_count
        features = [feature_names[i] for i in clf.tree_.feature]
        for i in range(0, n_nodes):
            threshold = clf.tree_.threshold[i]
            if threshold != -2.0:          # -2 表示叶节点
                data.append([t, i, clf.tree_.children_left[i],
                             clf.tree_.children_right[i], threshold, features[i]])
    return pd.DataFrame(data, columns=["Tree","NodeID","LeftID","RightID","Threshold","Feature"])
```

### 2.3 第二步：`get_feature_table` —— 区间 × 分裂的 0/1 矩阵

对某个特征，取出它的所有分裂点并按阈值排序。对每一行（一个候选区间，用该区间下界 `Threshold` 代表），逐列判断"在某个分裂节点上，这个区间值是 0 还是 1"：

```python
def get_feature_table(splits_data, feature_name):
    feature_data = splits_data[splits_data["Feature"]==feature_name].sort_values(by="Threshold")
    feature_data = feature_data.reset_index(drop=True)
    code_table = pd.DataFrame()
    code_table["Threshold"] = feature_data["Threshold"]
    for tree_id, node in zip(list(feature_data["Tree"]), list(feature_data["NodeID"])):
        colname = "s"+str(tree_id)+"_"+str(node)          # 列名：s树号_节点号
        code_table[colname] = np.where((code_table["Threshold"] <=
                                        feature_data[(feature_data["NodeID"]== node) &
                                                     (feature_data["Tree"]==tree_id)]["Threshold"].values[0]), 0, 1)
    # 补一行代表"大于最大阈值"的情况
    temp = [max(code_table["Threshold"])+1]
    temp.extend(list([1]*(len(code_table.columns)-1)))
    code_table.loc[len(code_table)] = temp
    return code_table.drop_duplicates(subset=['Threshold']).reset_index(drop=True)
```

**含义**：第 i 行、第 `s{t}_{n}` 列 = "如果该特征值落在第 i 个区间，那么在树 t 的节点 n 处，`x <= 阈值` 是否成立"（0 成立 / 1 不成立）。

**潜在问题和改进建议**

**1. 精度丢失**

```python
# 问题：不同阈值可能被取整为相同值
thresholds = [25.3, 25.7, 25.9]
# astype(int) → [25, 25, 25]  ❌ 丢失了区分度
```

**2. 建议改进**

```python
def get_feature_table(splits_data, feature_name):
    feature_data = splits_data[splits_data["Feature"]==feature_name].copy()
    if len(feature_data) == 0:
        return pd.DataFrame(columns=['Threshold'])
    
    # 保留精度，四舍五入到2位小数
    feature_data["Threshold"] = feature_data["Threshold"].round(2)
    feature_data = feature_data.sort_values(by="Threshold").reset_index(drop=True)
    
    # 使用唯一阈值
    unique_thresholds = feature_data["Threshold"].unique()
    code_table = pd.DataFrame({"Threshold": unique_thresholds})
    
    for _, row in feature_data.iterrows():
        colname = f"s{row['Tree']}_{row['NodeID']}"
        code_table[colname] = (code_table["Threshold"] > row["Threshold"]).astype(int)
    
    # 添加最大阈值以上的行
    max_threshold = code_table["Threshold"].max()
    new_row = [max_threshold + 1] + [1] * (len(code_table.columns) - 1)
    code_table.loc[len(code_table)] = new_row
    
    return code_table.drop_duplicates(subset=['Threshold']).reset_index(drop=True)
```

**总结**

这个函数的作用是**为特征创建编码查找表**，将连续特征值映射为二进制编码向量，每个编码位对应一个决策树中的分裂节点。这种编码方式在特征工程和模型解释中很有用。



**核心原因：我们要"模拟"决策树的判断过程**

**决策树是怎么判断的？**

假设我们有一个节点：`年龄 <= 30岁？`

**当你输入一个年龄时**：

```
输入年龄 = 28
判断：28 <= 30? → 是 → 走左

输入年龄 = 35  
判断：35 <= 30? → 否 → 走右
```

**编码表的本质：预计算所有可能的年龄值**

**问题**：如果有1000个不同的年龄值，每个都要去和30比较吗？

**答案**：不用！我们可以预先算好：

```
把所有可能的年龄分成几个区间：
[-∞, 25], (25, 30], (30, 35], (35, 40], (40, +∞]

每个区间内，所有年龄的判断结果都一样！
```

**为什么用其他阈值来赋值？**

**场景：我们有4个判断节点**

```
4个节点要判断：
节点s1_1: 年龄 <= 25?
节点s0_1: 年龄 <= 30?
节点s1_0: 年龄 <= 45?
节点s0_0: 年龄 <= 50?
```

**传统的做法（逐个判断）**

```python
年龄 = 28

判断1: 28 <= 25? → 否 → 1
判断2: 28 <= 30? → 是 → 0
判断3: 28 <= 45? → 是 → 0
判断4: 28 <= 50? → 是 → 0

结果 = [1, 0, 0, 0]
```

**编码表的做法（预计算区间）**

**关键思想**：观察这4个阈值

```
阈值按大小排序：25 < 30 < 45 < 50

对于任何一个年龄值：
- 它会在这些阈值之间"穿过"
- 每穿过一个阈值，就有一个节点"从0变成1"
```

**为什么？**

因为如果年龄 **> 25**，那么：

- 对节点s1_1（阈值25）：判断结果是"否" → 编码1
- 对节点s0_1（阈值30）：还需要看是否 > 30

如果年龄 **> 30**，那么：

- 对节点s0_1（阈值30）：判断结果是"否" → 编码1
- 对节点s1_0（阈值45）：还需要看是否 > 45

**所以规律是**：

```
年龄增大 → 依次超过25、30、45、50
         → 编码从 0000 逐渐变成 1111
```

**可视化：为什么"跨过阈值"会改变编码**

```python
数轴上的4个阈值：
----|----|----|----|----|---->
   25   30   45   50

年龄=20: 在25左边
  s1_1(25): 20<=25? 是 → 0
  s0_1(30): 20<=30? 是 → 0
  s1_0(45): 20<=45? 是 → 0
  s0_0(50): 20<=50? 是 → 0
  编码: [0,0,0,0]

年龄=28: 在25和30之间（跨过25）
  s1_1(25): 28<=25? 否 → 1  ← 改变了！
  s0_1(30): 28<=30? 是 → 0
  s1_0(45): 28<=45? 是 → 0
  s0_0(50): 28<=50? 是 → 0
  编码: [1,0,0,0]

年龄=35: 在30和45之间（跨过30）
  s1_1(25): 35<=25? 否 → 1
  s0_1(30): 35<=30? 否 → 1  ← 改变了！
  s1_0(45): 35<=45? 是 → 0
  s0_0(50): 35<=50? 是 → 0
  编码: [1,1,0,0]

年龄=48: 在45和50之间（跨过45）
  s1_1(25): 48<=25? 否 → 1
  s0_1(30): 48<=30? 否 → 1
  s1_0(45): 48<=45? 否 → 1  ← 改变了！
  s0_0(50): 48<=50? 是 → 0
  编码: [1,1,1,0]

年龄=55: 在50右边（跨过50）
  s1_1(25): 55<=25? 否 → 1
  s0_1(30): 55<=30? 否 → 1
  s1_0(45): 55<=45? 否 → 1
  s0_0(50): 55<=50? 否 → 1  ← 改变了！
  编码: [1,1,1,1]
```



**编码表如何利用这个规律**

```python
# 编码表的构建逻辑
阈值列表 = [25, 30, 45, 50]  # 排序后

# 对于每个阈值行，用"当前阈值"去判断"其他阈值"
行0 (阈值25):
  对所有节点问：25 <= 该节点阈值吗？
  s1_1(25): 25<=25? 是 → 0  (等于，所以是0)
  s0_1(30): 25<=30? 是 → 0
  s1_0(45): 25<=45? 是 → 0
  s0_0(50): 25<=50? 是 → 0
  结果: [0,0,0,0]  ← 全0

行1 (阈值30):
  对所有节点问：30 <= 该节点阈值吗？
  s1_1(25): 30<=25? 否 → 1  ← s1_1的阈值是25，30>25所以是1
  s0_1(30): 30<=30? 是 → 0
  s1_0(45): 30<=45? 是 → 0
  s0_0(50): 30<=50? 是 → 0
  结果: [1,0,0,0]

行2 (阈值45):
  对所有节点问：45 <= 该节点阈值吗？
  s1_1(25): 45<=25? 否 → 1
  s0_1(30): 45<=30? 否 → 1
  s1_0(45): 45<=45? 是 → 0
  s0_0(50): 45<=50? 是 → 0
  结果: [1,1,0,0]

行3 (阈值50):
  对所有节点问：50 <= 该节点阈值吗？
  s1_1(25): 50<=25? 否 → 1
  s0_1(30): 50<=30? 否 → 1
  s1_0(45): 50<=45? 否 → 1
  s0_0(50): 50<=50? 是 → 0
  结果: [1,1,1,0]
```

**总结**

**为什么用阈值去判断与别的阈值比较？**

因为：

1. **每个节点有自己的阈值**（25, 30, 45, 50）
2. **当特征值跨过某个阈值时**，对应节点的判断结果会从"是(0)"变成"否(1)"
3. **用当前行的阈值去和所有节点阈值比较**，就是在模拟"如果特征值等于这个阈值，每个节点会怎么判断"

**简单说**：

```python
编码表的每一行 = 模拟"特征值正好等于这个阈值"时，所有节点的判断结果

行1 (阈值30) = 模拟"特征值=30"时的判断：
  s1_1(25): 30>25 → 否 → 1
  s0_1(30): 30=30 → 是 → 0
  s1_0(45): 30<45 → 是 → 0
  s0_0(50): 30<50 → 是 → 0
  结果: [1,0,0,0]
```

这就是为什么用"阈值去判断别的阈值"——因为**阈值本身就是特征值的一个代表**，用阈值去比较，就能计算出该阈值下所有节点的判断结果！



### 2.4 第三步：`get_feature_codes_with_ranges` —— 生成表项内容

把同一树的所有 `s{t}_*` 列拼成一个**二进制码字**，同时生成每个区间的 `[start, end]`：

```python
def get_feature_codes_with_ranges(feature_table, num_of_trees):
    Codes = pd.DataFrame()
    for tree_id in range(num_of_trees):
        cols = [c for c in feature_table.columns if ('s'+str(tree_id)+'_') in c]
        Codes["code"+str(tree_id)] = feature_table[cols].apply(
            lambda x: "0b" + ''.join(x.astype(str)), axis=1)
    # Range 生成：第一行 [0, t0]；中间 (t_{i-1}, t_i]；末行 [t_last, t_last]

            feature_table.loc[i, "Range"] = str(feature_table.loc[i-1,"Threshold"]+1)+","+str(feature_table.loc[i,"Threshold"])
    return feature_table["Range"], Codes
```

## 3. 码表：根到叶路径的 ternary 匹配

### 3.1 问题

一棵树有 ~350 个叶节点。要判断"这一堆特征码字走到哪个叶"，需要把整棵树的**所有分裂答案**合成一条路径码，再和每条"叶路径码"比对。

### 3.2 `retrieve_branches` —— 枚举所有根到叶路径

用迭代方式从树结构里回溯出每条路径（一个节点序列）：

```python
def retrieve_branches(estimator):
    number_nodes = estimator.tree_.node_count
    children_left_list = estimator.tree_.children_left
    children_right_list = estimator.tree_.children_right
    feature = estimator.tree_.feature
    threshold = estimator.tree_.threshold
    # Calculate if a node is a leaf
    is_leaves_list = [(False if cl != cr else True) for cl, cr in zip(children_left_list, children_right_list)]
    # Store the branches paths
    paths = []
    for i in range(number_nodes):
        if is_leaves_list[i]:
            # Search leaf node in previous paths
            end_node = [path[-1] for path in paths]
            # If it is a leave node yield the path
            if i in end_node:
                output = paths.pop(np.argwhere(i == np.array(end_node))[0][0])
                yield output
        else:
            # Origin and end nodes
            origin, end_l, end_r = i, children_left_list[i], children_right_list[i]
            # Iterate over previous paths to add nodes
            for index, path in enumerate(paths):
                if origin == path[-1]:
                    paths[index] = path + [end_l]
                    paths.append(path + [end_r])
            # Initialize path in first iteration
            if i == 0:
                paths.append([i, children_left_list[i]])
                paths.append([i, children_right_list[i]])
    # 利用 children_left/right 反复扩展路径，遇到叶节点就产出该路径
```

**函数整体功能**

遍历决策树，找到所有从根节点到叶节点的完整路径，并逐个返回（yield）。

#### **逐行详细解析**

**1. 获取树的基本信息**

```python
number_nodes = estimator.tree_.node_count
children_left_list = estimator.tree_.children_left
children_right_list = estimator.tree_.children_right
feature = estimator.tree_.feature
threshold = estimator.tree_.threshold
```

**获取决策树的核心数据结构**：

- `node_count`：树的总节点数
- `children_left_list`：每个节点的左子节点ID（-1表示无）
- `children_right_list`：每个节点的右子节点ID（-1表示无）
- `feature`：每个节点使用的特征索引
- `threshold`：每个节点的分裂阈值

**2. 判断哪些节点是叶节点**

```python
is_leaves_list = [(False if cl != cr else True) for cl, cr in zip(children_left_list, children_right_list)]
```

**逻辑**：

- 如果 `left_child == right_child`，说明该节点没有子节点（都是-1），是叶节点
- 否则是内部节点

**示例**：

```python

#      children_right = [2, 4, -1, -1, -1]

# 判断：
节点0: left=1, right=2 → 1!=2 → False (内部节点)
节点1: left=3, right=4 → 3!=4 → False (内部节点)
节点2: left=-1, right=-1 → -1==-1 → True (叶节点)
节点3: left=-1, right=-1 → -1==-1 → True (叶节点)
节点4: left=-1, right=-1 → -1==-1 → True (叶节点)

# is_leaves_list = [False, False, True, True, True]
```

**3. 存储路径和遍历**

```python
paths = []
for i in range(number_nodes):
    # ... 处理每个节点
```

**paths 数据结构**：列表的列表，每个子列表是一条从根到当前节点的路径。

**4. 处理叶节点**

```python
if is_leaves_list[i]:
    # 找到所有路径中最后一个节点是 i 的
    end_node = [path[-1] for path in paths]
    # 如果当前叶节点在路径末尾，输出该路径
    if i in end_node:
        output = paths.pop(np.argwhere(i == np.array(end_node))[0][0])
        yield output
```

**逻辑**：

1. 如果当前节点是叶节点
2. 在 `paths` 中找到以该节点结尾的路径
3. 从 `paths` 中移除该路径
4. 返回（yield）该路径

**5. 处理内部节点**

```python
else:
    origin, end_l, end_r = i, children_left_list[i], children_right_list[i]
    # 遍历已有路径，扩展路径
    for index, path in enumerate(paths):
        if origin == path[-1]:
            paths[index] = path + [end_l]
            paths.append(path + [end_r])
    # 初始化根节点
    if i == 0:
        paths.append([i, children_left_list[i]])
        paths.append([i, children_right_list[i]])
```

**逻辑**：

1. 如果是内部节点，获取它的左右子节点
2. 遍历已有的路径，找到以当前节点结尾的路径
3. 将该路径扩展为两条：一条加上左子节点，一条加上右子节点
4. 如果是根节点（i=0），初始化两条路径

### 3.3 `get_leaf_paths` —— 路径 → 0/1 码

每条路径上，走到左子记 0、右子记 1，得到一串"方向码"：

```python
def get_leaf_paths(clf):
    for branch in retrieve_branches(clf):
        code = [0]*len(branch)
        for i in range(1, len(branch)):
            if branch[i] == clf.tree_.children_left[branch[i-1]]:
                code[i] = 0
            else:
                code[i] = 1
        yield code[1:]
```

**函数整体功能**

从 `retrieve_branches` 获取的路径中，提取每个节点的**方向编码**（0=左转，1=右转），并输出从根到叶子的转向序列。

#### 逐行详细解析

**1. 遍历所有路径**

```python
for branch in retrieve_branches(clf):
```

**输入**：`branch` 是一条从根到叶的路径，例如 `[0, 1, 3]`

**含义**：路径中的每个数字是节点ID，从根节点到叶节点。

**2. 初始化编码**

```python
code = [0]*len(branch)
```

**功能**：创建一个和路径长度相同的列表，初始值全为0。

**示例**：

```python
branch = [0, 1, 3]  # 3个节点
code = [0, 0, 0]    # 初始化
```

**3. 遍历路径中的每个步骤**

```python
for i in range(1, len(branch)):  # 从第2个节点开始（跳过根节点）
```

**为什么从1开始？**

- `i=0` 是根节点，它没有父节点，无法判断方向
- 从 `i=1` 开始，判断从父节点到当前节点是左转还是右转

**4. 判断方向**

```python
if branch[i] == clf.tree_.children_left[branch[i-1]]:
    code[i] = 0  # 是左子节点 → 编码0
else:
    code[i] = 1  # 是右子节点 → 编码1
```

**关键逻辑**：

- `branch[i-1]`：当前节点的父节点
- `clf.tree_.children_left[父节点]`：父节点的左子节点ID
- 如果当前节点等于父节点的左子节点 → 左转 → 编码0
- 否则 → 右转 → 编码1

**5. 返回编码**

```python
yield code[1:]  # 去掉第一个元素（根节点没有方向）
```

**为什么去掉 `code[0]`？**

- `code[0]` 对应根节点，它没有父节点，所以没有方向
- 有用的编码从 `code[1]` 开始

```python
                clf.tree_.children_right[i],  # RightID
                clf.tree_.threshold[i],       # Threshold
                features[i]                   # Feature
```

**核心价值**：将决策树内部难以直接使用的数据结构，转换为清晰易用的DataFrame格式，便于后续分析和处理。



### 3.5 `get_order_of_splits`

```cpp
def get_order_of_splits(data, feature_names):
    splits_order = []
    for feature_name in feature_names:
        feature_data = data[data.iloc[:,4]==feature_name]
        feature_data = feature_data.sort_values(by="Threshold")
        for node in list(feature_data.iloc[:,0]):
            splits_order.append(node)
    return splits_order
```

**split里面存储的是非叶子节点**

### 3.6 `get_codes_and_masks` —— 全局分裂顺序 + 掩码

一棵树的内部节点（分裂点）需要按**固定顺序**排成码位。`get_order_of_splits` 按"特征名 → 阈值"排序所有分裂点，得到全局顺；每条路径只在其中**经过的分裂位**上填 0/1，其余位用 `mask=0` 掩盖：

```python
def get_codes_and_masks(clf, feature_names):
    splits = get_order_of_splits(get_splits_per_tree(clf, feature_names), feature_names)
    depth = clf.max_depth
    codes = []
    masks = []
    for branch, coded in zip(list(retrieve_branches(clf)), get_leaf_paths(clf)):
        code = [0]*len(splits)
        mask = [0]*len(splits)
        for index, split in enumerate(splits):
            if split in branch:
                mask[index] = 1
        masks.append(mask)
        codes.append(code)
    masks = pd.DataFrame(masks)
    masks['Mask'] = masks[masks.columns[0:]].apply(lambda x: ''.join(x.dropna().astype(str)),axis=1)
    masks = ["0b" + x for x in masks['Mask']]
    indices = range(0,len(splits))
    temp = pd.DataFrame(columns=["split", "index"],dtype=object)
    temp["split"] = splits
    temp["index"] = indices
    final_codes = []
    for branch, code, coded in zip(list(retrieve_branches(clf)), codes, get_leaf_paths(clf)):
        indices_to_use = temp[temp["split"].isin(branch)].sort_values(by="split")["index"]
        for i, j in zip(range(0,len(coded)), list(indices_to_use)):
            code[j] = coded[i]
        final_codes.append(code)
    final_codes = pd.DataFrame(final_codes)
    final_codes["Code"] = final_codes[final_codes.columns[0:]].apply(lambda x: ''.join(x.dropna().astype(str)),axis=1)
    final_codes = ["0b" + x for x in final_codes["Code"]]
    return final_codes, masks
```

> 这就是"**ternary**"的由来：`codeword` 是路径码，`codeword_mask` 指明哪些位必须参与比较。命中即走到该叶节点。

### 3.7 `get_classes` —— 叶节点 → 类别 + 置信度

每个叶节点的 `value` 是各类别样本数分布，取 `argmax` 为类别、占比为置信度 `cert`：

```python
def get_classes(clf):
    leaves = []
    classes = []
    certainties = []
    for branch in list(retrieve_branches(clf)):
        leaves.append(branch[-1])
    for leaf in leaves:
        if clf.tree_.n_outputs == 1:
            value = clf.tree_.value[leaf][0]
        else:
            value = clf.tree_.value[leaf].T[0]
        class_name = np.argmax(value)
        certainty = int(round(max(value)/sum(value),2)*100)
        classes.append(class_name)
        certainties.append(certainty)
    return classes, certainties
```

**函数整体功能**

遍历决策树的所有叶节点，返回两个列表：

1. **每个叶节点的预测类别**
2. **每个叶节点的置信度（百分比）**

## 4. 投票表：多数表决

### 4.1 为什么需要

三棵树各自给一个类别（`class0/1/2`），最终类别按**多数投票**决定。投票表把"三个类别组合"映射为"最终类别"：

```cpp
table voting_table {
    key = {
        meta.class0: exact;                  // 树0的类别
        meta.class1: exact;                  // 树1的类别
        meta.class2: exact;                  // 树2的类别
    }
    actions = { set_final_class; @defaultonly nop; }
    size = 1000;
    const default_action = nop();
}
action set_final_class(bit<8> class_result) {
    meta.final_class = class_result;
}
```

### 4.2 表项生成

穷举三类别组合，多数一致取多数、全不一致随机取一个：

```python
for i in range(1, 17):
    for j in range(1, 17):
        for k in range(1, 17):
            if (i!=j) & (j!=k) & (i!=k):
                result = np.random.choice([i, j, k])     # 平局随机
            else:
                result = mode([i, j, k])                 # 多数
            print(f"voting_table.add_with_set_final_class(class0={i}, class1={j}, class2={k}, class_result={result})")
```

> 本课真实模型：16 类 → 16³ = 4096 条投票表项。

## 5. 串联起来：一条报文如何被分类

以第 2 课模型（3 棵树、7 特征）为例：

```
第 3 个包到达
  │
  ├─ table_feature0..6.apply()   7 张特征表：每个特征命中一个区间
  │     每张表 SetCode* 把区间对应的码字片段写进 codeword0/1/2
  │
  ├─ code_table0..2.apply()      3 张码表：用 [codeword, mask] 匹配叶路径
  │     命中后 SetClass* 输出 class0/1/2 与 cert
  │
  └─ voting_table.apply()        1 张投票表：(class0,class1,class2) → final_class
       set_final_class 把最终类别写进 meta.final_class
```

**为什么每棵树只要 3 张表？** 因为"比较 → 区间码 → 路径码 → 类别"的每一步都恰好是一个表能表达的运算。这就是 Flowrest 选择随机森林的深层原因——**模型结构恰好匹配交换机表结构**。

## 7. 本课小结

- 树 → 三类表：特征表（range 算区间码）→ 码表（ternary 匹配路径）→ 投票表（exact 表决）。
- 编码三件套：区间（Range）、码字（Code）、掩码（Mask），分别由三个函数族生成。
- 叶子→类别用 `argmax`、置信度用占比；路径回溯用 `retrieve_branches`。
- 实测产物规模：特征表 140 条 / 码表 350 条 / 投票表 4096 条（3 树、350 叶、16 类）。
- 修复了新版 pandas 下的链式赋值 Bug（Range 列丢失），并让脚本支持命令行传入模型文件。
