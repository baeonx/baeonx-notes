### 2. 头部定义（Headers）

#### ① `ethernet_t` （标准以太网头）

| 字段        | 长度   | 作用                                    |
| :---------- | :----- | :-------------------------------------- |
| `dstAddr`   | 48 bit | 目的MAC地址                             |
| `srcAddr`   | 48 bit | 源MAC地址                               |
| `etherType` | 16 bit | 上层协议类型（0x800=IPv4，0x812=Probe） |

#### ② `ipv4_t` （标准IPv4头）

只列出关键字段：

- `ttl`：生存时间，每跳减1
- `srcAddr` / `dstAddr`：源/目的IP
- 其余为标准字段（版本、长度、校验和等）

#### ③ `probe_t` （探测头）

| 字段      | 长度  | 作用                                         |
| :-------- | :---- | :------------------------------------------- |
| `hop_cnt` | 8 bit | **当前已跳数**，初始为0，每经过一台交换机加1 |

#### ④ `probe_data_t` （每跳记录的数据）

| 字段        | 长度   | 作用                                                         |
| :---------- | :----- | :----------------------------------------------------------- |
| `bos`       | 1 bit  | **Bottom Of Stack**，标识是否为最后一个数据条目（用于变长数组解析） |
| `swid`      | 7 bit  | 交换机ID（标识当前是哪台交换机）                             |
| `port`      | 8 bit  | 数据包从该交换机的**哪个入口端口**进来                       |
| `byte_cnt`  | 32 bit | 该交换机当前累计处理的字节数（或时间戳计数）                 |
| `last_time` | 48 bit | 上一次记录的时间                                             |
| `cur_time`  | 48 bit | 当前记录的时间（用于计算延迟）                               |

#### ⑤ `probe_fwd_t` （转发指示头）

| 字段          | 长度  | 作用                                                     |
| :------------ | :---- | :------------------------------------------------------- |
| `egress_spec` | 8 bit | 告诉交换机**应该从哪个端口**发出这个探测包（下一跳出口） |

------

### 3. 元数据（Metadata）

- **`parser_metadata_t`**：包含 `remaining`（剩余待解析的probe_data数量），用于控制解析循环。
- **`metadata`**：包含 `egress_spec`（最终出口端口），以及 `parser_metadata`。

------

### 4. 数据包结构（重点）

`headers` 结构体定义了**完整的报文格式**：

```cpp
struct headers {
    ethernet_t              ethernet;          // 1. 以太网头
    ipv4_t                  ipv4;              // 2. IPv4头
    probe_t                 probe;             // 3. 探测控制头
    probe_data_t[MAX_HOPS]  probe_data;        // 4. 数组：每跳的记录数据（最多10个）
    probe_fwd_t[MAX_HOPS]   probe_fwd;         // 5. 数组：每跳的转发指令（最多10个）
}
```



------

### 5. 数据包堆叠结构图（可视化）

下面是把这些头部**按顺序堆叠**的示意图（从左到右为包起始到结束）：

```
+------------------+
|  Ethernet Header |   (dstMAC + srcMAC + etherType = 0x812)
+------------------+
|   IPv4 Header    |   (标准IP头，协议字段可能标识为自定义)
+------------------+
|   Probe Header   |   (hop_cnt = 当前跳数)
+------------------+
| Probe_Data[0]    |   ← 第0跳交换机记录 (swid, port, byte_cnt, times)
+------------------+
| Probe_Data[1]    |   ← 第1跳交换机记录
+------------------+
|      ...         |
+------------------+
| Probe_Data[n-1]  |   ← 第n-1跳交换机记录（n = hop_cnt）
+------------------+
| Probe_Fwd[0]     |   ← 第0跳交换机要使用的出口端口
+------------------+
| Probe_Fwd[1]     |   ← 第1跳交换机要使用的出口端口
+------------------+
|      ...         |
+------------------+
| Probe_Fwd[n-1]   |   ← 第n-1跳交换机要使用的出口端口
+------------------+
```



**关键点**：

- `probe_data` 和 `probe_fwd` 是**两个独立的数组**，长度都等于 `MAX_HOPS`。
- 当交换机收到包时，它读取 `probe.hop_cnt`，用这个索引访问：
  - `probe_data[hop_cnt]` 来**写入**自己的信息
  - `probe_fwd[hop_cnt]` 来**读取**下一跳出口端口
- 然后 `hop_cnt++`，并将包从指定端口转发出去。
