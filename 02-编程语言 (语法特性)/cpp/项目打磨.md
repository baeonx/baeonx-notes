```
首先，提取原始决策树所有非叶子节点，按照特征名与同特征名下的阈值进行排序，得到节点序列表，并记录各节点在所述节点序列表中的位置与其在原始决策树中位置的映射关系；然后，提取从根节点到各叶子节点的路径；接着，根据所述映射关系，将每条路径经过的节点在节点序列表中的对应位置置1、其余置0，得到节点编码 map_code；按照父节点到左孩子记为0、到右孩子记为1的规则，得到每条路径的方向编码 mask_map；最后，将 map_code 与 mask_map 按位与运算，运算结果与该路径对应的分类结果关联，形成匹配-动作表项；汇总所有叶子节点对应的匹配-动作表项，即构成所述 code0 表。
```
