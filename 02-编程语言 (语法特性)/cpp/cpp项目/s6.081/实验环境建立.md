① 启动 mihomo(用你自带的 clashon):

```bash
clashon
```

② 启动 socat(容器用代理的桥):

```bash
setsid socat TCP-LISTEN:7890,fork,reuseaddr,bind=172.18.0.1 TCP:127.0.0.1:7890 < /dev/null > /dev/null 2>&1 &
```


③ 验证:

```bash
curl -x http://127.0.0.1:7890 -o /dev/null -w "%{http_code}\n" https://github.com
```

**返回 200 就通了**

④ 推送:

```bash
git push
```


提示:你的 p4start 别名其实已经把 ①② 合在一起了,如果 p4 容器也开着,直接跑 p4start 一条龙。当前 mihomo 和 socat 我已经帮你拉起来了(验证 github 200),你现在直接 git push 就行。
